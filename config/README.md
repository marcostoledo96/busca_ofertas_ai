# Configuración de ejemplo

Los archivos de esta carpeta son ejemplos versionados. La configuración personal real se guardará en los directorios XDG del usuario y no debe incorporarse al repositorio.

- `searches/*.example.yml`: ejemplos que deben validar contra el schema vigente.
- no incluir sesiones, tokens, cookies o ubicaciones privadas innecesarias;
- la búsqueda Switch Lite es el primer caso, no una constante global.
